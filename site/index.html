    Como rodar no seu sistema

    Claude CodeNo app desktop ou no terminal, com plano pago. No chat comum do claude.ai não funciona.
    Seu computadorO sistema precisa estar rodando localmente, em localhost, ou em um ambiente de homologação.
    Uma pasta de projetoOs agentes leem o código e abrem o sistema no navegador para testar.
    1. 1

      Abra o Claude Code na pasta do projeto

      No terminal, entre na pasta do seu sistema e abra o Claude Code. No app desktop, escolha a pasta.

      cd caminho/do/seu-projeto && claude
    2. 2

      Instale o Esquadrão QA

      Cole os dois comandos, um de cada vez. Eles baixam a skill do repositório.

      /plugin marketplace add dimitresouza12/esquadrao-qa
      /plugin install esquadrao-qa@esquadrao-qa
    3. 3

      Rode e responda duas perguntas

      Ele pergunta o endereço local do seu sistema e se você quer o modo leve ou o completo. Depois mostra um endereço local (localhost) para abrir no navegador, onde a cena acompanha o seu teste de verdade.

      /esquadrao-qa:testar

    Os 22 agentes e o que cada um testa

    O modo leve roda os 5 marcados. No modo completo, a skill lê o seu projeto primeiro e escala só os agentes que fazem sentido para ele.

    O que ele nunca faz

    • Testa só em localhost ou homologação. Se detectar um endereço de produção, para e pergunta.
    • Não usa credenciais de produção, não faz deploy, não faz push e não apaga dados reais.
    • Cria dados de teste com o prefixo QA e só limpa no final, com a sua confirmação.
    • Pede permissão antes de instalar qualquer ferramenta, como o Playwright.

    Perguntas frequentes

    Funciona no chat do claude.ai?

    Não. Os agentes rodam comandos, abrem um navegador e leem o seu projeto, e isso só acontece no Claude Code.

    Posso rodar no sistema que já está no ar?

    Não. Rode no seu computador ou em homologação. Alguns testes criam e alteram dados, e os de segurança fazem requisições agressivas.

    Os meus dados saem do computador?

    O relatório e a cena ficam na sua máquina. O Claude processa o que lê do seu projeto, como em qualquer sessão do Claude Code.

    Quanto de uso isso gasta?

    Cada agente consome uma fatia real do limite do seu plano. Por isso existe o modo ultraleve (2 agentes), pensado para caber até numa janela de uso curta; o leve (5) e o completo (até 22) gastam mais, e os agentes rodam em lotes de 3 para não estourar tudo de uma vez. Se o limite acabar no meio, o teste pode ser retomado depois de onde parou, sem perder o que já rodou.
